# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-05
### Added
- Complete Authentication flow (Signup, Login, OTP, Forgot Password).
- Student Dashboard for tracking enrolled courses.
- Course Purchasing workflow via Razorpay integration.
- Instructor Analytics Dashboard with MongoDB aggregation.
- Course Builder for creating Sections and SubSections (videos).
- Rich text support and image uploading via Cloudinary.
- Comprehensive UI styling with Tailwind CSS and Glassmorphism effects.
- Dynamic Catalog Dropdown in Navbar.
- Ratings and Reviews system.
- Secure environment configuration for production.
