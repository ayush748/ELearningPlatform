# Contributing to StudyNotion

First off, thank you for considering contributing to StudyNotion! It's people like you that make StudyNotion such a great platform.

## How to Contribute

### Reporting Bugs
If you find a bug, please create an issue on GitHub with the following details:
- A clear and descriptive title.
- Steps to reproduce the issue.
- The expected behavior and what actually happened.
- Screenshots or console logs if applicable.

### Suggesting Enhancements
Have an idea for a new feature? We'd love to hear it! Open an issue and provide:
- A description of the proposed feature.
- Why it would be useful to students or instructors.
- Any mockups or technical suggestions you have in mind.

### Pull Requests
1. Fork the repository and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. If you've changed APIs, update the documentation.
4. Ensure the test suite passes (`npm run build` and `npm run lint`).
5. Issue a pull request with a comprehensive description of the changes.

## Development Setup
Please refer to the `README.md` for instructions on how to set up the Frontend and Backend servers locally.

Thank you for contributing!
